# SMM Ahsan

Social media marketing for local businesses. Based in Malta, working with clients in Europe and Pakistan.

Website: https://smmahsan.com

## Open source tools

50 small, free Python tools. Nothing to install beyond Python itself, no dependencies, and every tool is MIT licensed, so use them freely.

### For small businesses and work

- **CaptionCraft** — draft social media captions and hashtag sets for local businesses: https://github.com/smm-ahsan/captioncraft
- **InvoiceCraft** — generate clean HTML invoices from the command line: https://github.com/smm-ahsan/invoicecraft
- **ReviewReply** — draft polite, human replies to customer reviews: https://github.com/smm-ahsan/reviewreply
- **PostPlanner** — generate a 7-day social media content calendar as a CSV file: https://github.com/smm-ahsan/postplanner
- **ShiftCalc** — calculate shift hours and gross pay, including overnight shifts: https://github.com/smm-ahsan/shiftcalc
- **CurrencyText** — write money amounts in words and convert currencies with a rate you supply: https://github.com/smm-ahsan/currencytext
- **EmailCraft** — draft everyday business emails from simple templates: https://github.com/smm-ahsan/emailcraft
- **PitchCraft** — write a spoken 30 or 60 second elevator pitch script for your business: https://github.com/smm-ahsan/pitchcraft
